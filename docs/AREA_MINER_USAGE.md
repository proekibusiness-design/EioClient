# Area Miner usage

1. Stand at one corner of the intended mining rectangle at the desired surface and run `/eio area pos1`.
2. Stand at the opposite corner and run `/eio area pos2`.
3. Set Area Miner's `Depth` in multiples of 5.
4. Enable Area Miner.
5. Use `/eio area status` to inspect selected bounds, current layer, lane, and target.
6. Use `/eio area clear` to clear the selection.

# Eio Client

A Fabric client project targeting Minecraft 26.3 with Java 25.

The current release line uses a compact glass ClickGUI, configurable gameplay/QoL modules, HUD telemetry, diagnostics, config recovery and stable key mappings. GitHub Actions compiles and deeply verifies the release artifact before upload.

Current release candidate: **0.15.0** (`EIO-015-QA1`).
